# CollectFlow dashboard

React/Vite frontend with the creditor layout from the supplied `App.jsx` reference. It includes role-specific agency overview and Daily Pulse views, the shared compact icon rail, a persistent light/dark theme, and the interactive cat companion.

Run `npm install` and `npm run dev` in this folder. Vite serves port 5174 and forwards `/api` to FastAPI on port 8000. The login app runs at port 5173 by default; set `VITE_LOGIN_URL` to override it.

The displayed portfolio figures and work items are marked sample preview data because this archive has no dashboard domain read APIs.
